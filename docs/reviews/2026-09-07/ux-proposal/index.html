PRODUCT / SEPTEMBER 2026·Illustrative proposal

Make the first five minutes simpler.

Help new teams reach their first useful result before asking them to configure their workspace.

Today, our example setup flow asks people to make several decisions before they see the product work. We propose a shorter path: one goal, a useful starting point, and a clear next step.

Decision

Move optional configuration out of onboarding. Show a starter workspace first, then let teams refine it as they work. This is a proposed product direction, ready for discussion and revision.

Plan

Start with the smallest useful version. Remove nonessential fields, offer one example, and use the first session to learn which step still needs explanation.

Measurement

Review activation for eligible new workspaces. Agree on the rollout date, observation window, and decision threshold before exposure. The target above is an example, not a result.
